# 📸 Portfolio Website  
🌐 [View the project](https://fiercesloth.github.io/portfolio-task/portfolio/)

**Portfolio Website** is a responsive landing page created as part of **[RS School](https://rs.school/) Stage#1**.  
The project was built according to a **Figma design mockup**, using only **HTML, SCSS, and JavaScript**, without any frameworks or external libraries.

---

## 📖 About the project  
- A modern, fully responsive portfolio website for a photographer.  
- Developed strictly following the Figma layout.  
- Built entirely with native technologies — no frameworks or libraries.  
- Includes smooth interactivity and animations for a polished user experience.

---

## 🎮 Functionality  
- **Burger menu** with smooth open/close animation.  
- **Popup form** for booking or contact.  
- **Image slider** showcasing photography works.  
- **FAQ section** with expandable questions.

---

## ✨ Features  
- Pixel-perfect responsive layout.  
- Clean and semantic **HTML5** structure.  
- **SCSS** with variables and mixins for maintainability.  
- **CSS3** transitions and animations for smooth effects.  
- Lightweight and optimized for performance.  
- Works across all modern browsers and devices.

---

## 🛠️ Tech Stack  
- **HTML5** — semantic markup  
- **SCSS (CSS3)** — responsive styling and animations  
- **Vanilla JavaScript (ES6)** — interactive functionality
